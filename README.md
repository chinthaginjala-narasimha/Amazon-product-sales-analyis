## 📌 Project Overview

The **Amazon Product Sales Analysis** project uses Microsoft Power BI to explore Amazon product data, including pricing, customer ratings, reviews, and product categories.

The objective is to transform product data into meaningful visualizations that help users compare products, explore customer feedback, and understand product-level patterns.

## 🎯 Project Objectives

- Analyze product prices and price variations.
- Explore customer ratings and review counts.
- Compare products across categories.
- Examine relationships between pricing and customer ratings.
- Identify highly rated products using available data.
- Build interactive reports for product-level exploration.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation, if used
- **DAX** – Measures and calculations, if implemented

## 🔍 Project Workflow

### 1. Data Preparation
- Import the Amazon product dataset into Power BI.
- Inspect columns and data types.
- Identify missing values and duplicate records.
- Clean and transform product data as required.

### 2. Data Analysis
- Explore product pricing patterns.
- Analyze customer ratings and review counts.
- Compare product categories.
- Investigate relationships between available product attributes.

### 3. Dashboard Development
- Design visualizations for product analysis.
- Use charts to compare product prices and ratings.
- Present category-level comparisons.
- Add slicers and filters where implemented.
- Organize visuals into an easy-to-understand report.

### 4. Insight Generation
- Explore product-level differences.
- Identify patterns in prices, ratings, and reviews.
- Present findings based on the actual dataset.

This project demonstrates how Power BI can help explore product data, compare pricing, examine customer feedback, and communicate patterns through visual reports.

The findings can support further investigation into product positioning and category performance.
